# Dilger Custom Cabinetry LLC

Marketing site for Dilger Custom Cabinetry LLC, a custom cabinetry and carpentry
shop in Bothell, WA serving King and Snohomish counties.

- `index.html` — the live site (single-page, static, no build step)
- `planning/seo-roadmap.html` — internal launch/SEO checklist, not part of the
  public site

## Deploying

This is a static site with no build step — deploy `index.html` as-is (Netlify,
GitHub Pages, or any static host).
